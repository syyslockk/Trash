# Карта риска космического мусора

Учебный проект детского технопарка «Альтаир» (РТУ МИРЭА), направление «Прикладной анализ данных».

Тема: «Кластеризация объектов космического мусора и картирование зон повышенного риска столкновений на низких околоземных орбитах».

Автор: Ковылин Владимир Олегович. Руководитель: Борисов Артём Игоревич.

## Что делает приложение

Настольное приложение на Qt (PySide6), которое по открытым данным CelesTrak:

1. скачивает каталог объектов на орбите (спутники, ракетные ступени, обломки);
2. чистит и структурирует данные;
3. находит скопления объектов (HDBSCAN по высоте и наклонению) и проверяет их на известных облаках обломков;
4. считает относительный индекс риска столкновения спутников и ракетных ступеней с мусором;
5. показывает интерактивную карту риска и таблицу самых опасных зон.

> Индекс риска - **относительный** (от 0 до 1). Это **не вероятность столкновения**, а сравнение зон между собой.

## Структура

```
data/raw/         скачанные файлы (не в git)
data/processed/   результаты обработки и анализа (не в git)
docs/             описание проекта, отчёт; docs/prototypes - первые версии скриптов
resources/        иконки, стили, береговые линии для 3D-модели
source/
  config.py       пути, адреса, константы, параметры сетки и HDBSCAN
  loader/         1. загрузка с CelesTrak
  processing/     2. обработка
  analysis/       3. кластеризация, проверка, риск
  visualization/  4. карта риска
  app/            GUI на PySide6
tests/            тесты pytest
webui/            HTML-шаблон интерактивной карты
main.py           точка входа
```

Каждый шаг - отдельный модуль, который можно запустить сам по себе.

## Установка

Нужен Python 3.9 или новее.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Если на Apple Silicon не собирается пакет `hdbscan`, его можно не ставить: будет использован `sklearn.cluster.HDBSCAN`.

## Запуск

Загрузка данных (повторный запуск берёт файлы из кэша, `--force` скачивает заново):

```bash
python -m source.loader
python -m source.loader --force
```

Весь конвейер без окна:

```bash
python main.py --cli
```

Тесты:

```bash
python -m pytest
```

Готово: загрузка (`loader`). В разработке: `processing`, `analysis`, `visualization`, GUI.

## Данные

| Файл | Откуда | Что внутри |
|---|---|---|
| `data/raw/satcat.csv` | https://celestrak.org/pub/satcat.csv | весь каталог SATCAT: тип объекта (PAY, R/B, DEB, UNK), статус, перигей, апогей, наклонение |
| `data/raw/gp_<группа>.json` | https://celestrak.org/NORAD/elements/gp.php | элементы орбит GP/OMM для действующих спутников и четырёх облаков обломков |
| `data/raw/meta.json` | - | дата скачивания, адрес и число строк каждого файла |

Облака обломков: Fengyun-1C (2007), Iridium-33 и Cosmos-2251 (2009), Cosmos-1408 (2021).

## Ограничения модели

1. Индекс риска относительный, это не вероятность столкновения.
2. Плотность усредняется по слою высоты без учёта широты; орбиты считаются круговыми; размеры и массы объектов не учитываются.
3. В каталоге только отслеживаемые объекты (примерно от 10 см). Мелкие обломки не видны.
4. На 3D-модели положение объектов вдоль орбиты условное: в данных нет момента прохождения.
